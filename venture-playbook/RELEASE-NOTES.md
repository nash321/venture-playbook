## 本次已完成

核心脚本仅使用Python标准库。没有邮件、云盘、定时任务或专有站内接口集成，没有客户私有资源和付费原文案例。

## 必须保留的边界

当前受控浏览器不允许导航file://与本地回环地址。因此本次用真实Chromium加载自有HTML字符串进行渲染与交互验证，下载出的完整HTML也重新加载检查。没有关闭浏览器沙箱或改变安全策略。**没有据此声称原生file://存储在所有浏览器中均已验证。** 本地存储受限时，导出完整HTML与JSON备份仍是明确的保存路径。

未在所有Agent宿主、Windows、macOS、Safari、Firefox或用户实际购买环境中完成安装验收。已有官方目录安装依据不等于实装测试；销售页只应承诺自己验证过的范围。Python测试环境为3.13，代码目标3.10+，其他Python小版本需在目标环境复核。

测试验证结构和程序行为，不认证模型始终读全原文、网络来源永远有效、商业证据真实或客户必然赚钱。标准研究仍需要宿主具备真实公开搜索与阅读能力。

## 复测

```sh
python -m unittest discover -s tests -p "test_*.py" -v
python scripts/venture.py build examples/project-demo.json --out ./demo-fresh.html
python scripts/venture.py check ./demo-fresh.html
# 以下仅在已安装Playwright和浏览器的测试环境：
python tests/browser_smoke.py --report ./demo-fresh.html --out ./qa-output
python tests/storage_mock.py --report ./demo-fresh.html
```

`--markup`是显式的“只测试自有HTML内容”模式，不验证原生本地地址的访问和存储。`storage_mock.py`始终标注模拟存储，不将模拟结果当实机同步证明。

## 打包与更新

使用 `python scripts/release.py --out ./venture-playbook-v9.0.0.zip` 按白名单生成客户包与manifest。它不上传、不安装，拒绝已存在输出（除非显式--force），并检查常见私密配置/凭据模式。白名单与模式检查不是全面安全审计；新增文件前仍须人工确认来源、授权和是否包含客户数据。
