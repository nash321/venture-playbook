# V9.1.3 · 编辑与撤销自动存浏览器

编辑行动的有效修改会自动保存到当前浏览器，无需点“保存行动”；新增行动须填齐必填项。一次编辑可整体撤销，撤销结果也自动保存。关闭窗口保留有效修改，“撤销本次编辑”放弃本次修改。浏览器存储失败或输入不合法会明确提示，不冒充已保存。自动保存不改写HTML文件；移动、分享或换设备前仍需保存完整报告或备份待办。

# V9.1.2 · 待办手动调整顺序

复查补齐两处操作遗漏：浏览器删除或导入任务时，动作示例按当前清单说明是否已删除，保存副本保留该说明；撤销导入后，阶段显示与实际保存的数据同步恢复。

候选版增加白话导读、术语首次解释、首项行动示例和带章节回查的理解自检；旧数据兼容，原正文与客户任务不被摘要替换。只改阅读说明时沿用旧revision。客户删除示例对应任务后，恢复工具保留删除结果与原示例，并明确标记，不重新添加任务。真实理解验收与功能测试分别记录。

每项待办增加上移、下移，支持键盘操作和撤销；手机使用44像素按钮。未筛选且选择“我的顺序”时可以移动，日期/优先级查看及筛选时说明恢复方法。顺序随本地记录、备份、CSV及完整HTML保留，不改变内容、状态或任务依赖。

明确排查与验收不接入专用判断服务，不新增模型账号、SDK或密钥；保留本包脚本、实际操作和证据回读检查。

# V9.1.1 · 每份报告页底分享图卡

生成器在每份HTML正文最底部固定嵌入作者原始会员体验卡、分享入口与3天体验说明。图片字节不变，离线、转发和保存完整报告均保留；校验器检查图卡、链接与位置，防止遗漏或替换；拒绝图卡后追加正文导致图卡不再置底的报告。沿用现有报告与任务交互，首次提示记录不变。

SOP补齐编译、验收和交付终点及非本地宿主出口；明确复用已安装兼容Python的兜底。现有merge-tasks支持从保存HTML恢复待办和状态，禁止覆盖两个输入；doctor检查原海报并以非零退出报告缺依赖；引导状态增加选择和恢复步骤合法性校验；Gemini登录提示复用实际连接名。

# V9.1.0 · 默认配置与逐步引导

新增默认后台脚本全局安装与生财MCP配置，支持已核对默认格式的六类宿主。配置与OAuth独立；不联网安装依赖，不启动登录，保留其他服务器及已存在的同端点连接。
